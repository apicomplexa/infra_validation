## Решения пользователя (обязательны)

- Новый репозиторий; только Linux; отчёты только на русском; `licmatch` в `packages/`.
- Алкоголь: лицензия ЕГАИС засчитывается в «Подтверждено» только при совпадении имени
  (прямо, известный алиас, выученная пара с leave-one-out); по адресу / общей
  вывеске — слабая.
- До финальных XLSX по алкоголю и табаку конвейеры работают на v4 через адаптер.
- Агентов можно запускать; модель выбирать по задаче (Opus — архитектура и сложные
  правила, Sonnet — механический перенос).
