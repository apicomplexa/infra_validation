# S3: словарь признака «Алкоголь?»

Ресторан и банкетный зал сами по себе не доказывают продажу алкоголя. Стемы
отрицательного словаря без границы слова давали ложное «нет» для названий
вроде «Почтовая контора»; «безалкогольный» ошибочно давал «да».
Границы поставлены в начале отрицательных стемов, слова «ресторан» и «банкет»
убраны из положительных, а префикс «без» исключён из алкогольного стема.

## Что изменилось

На v4 при прежних свидетельствах ЕГАИС:

| Переход «Алкоголь?» | До | После | Записей |
|---|---|---|---:|
| Ресторан или банкет без иных голосов | да | нет данных | 20 |
| «Почтовая контора» без голоса лицензии | нет | нет данных | 1 |
| Остальные | прежнее значение | прежнее значение | 924 |

При совместном применении S2 и S3 итоговое распределение: «да» 408 → 393,
«нет» 9 → 8, «нет данных» 528 → 544, «противоречие» 0 → 0. S2 добавляет
голоса действующих лицензий; таблица выше изолирует изменение словаря.
Если сначала применить S2, «Почтовая контора» меняется из «противоречие»
в «да»: совпавшая действующая лицензия становится единственным голосом.
