# Склеенные объекты и голосование за вид — 21 ноября 2026

Связанные через relink записи и записи одного `egais_entity` образуют компоненты. Раньше итог считал компонент подтверждённым, если подтверждена хотя бы одна его запись, тогда как таблица сочетаний объединяла источники всех записей. Поэтому сочетание независимых источников могло указывать на подтверждение при нуле в итогах.

Теперь для каждой компоненты объединяются строки Evidence; обычное правило категории считает только сильные текущие находки, по одному голосу независимой группы, с порогом `min_sources`. Этот вердикт записан в `confirmed_object` и «Подтверждено (объект)», используется в итогах и согласован с таблицей «Источники объекта». Построчные `confirmed` и «Основания» не меняются. В итогах указывается число объектов, чей вердикт отличается от вердикта хотя бы одной записи: это ожидаемо. Отсутствующие поля связей и пустая поставка обрабатываются без исключений.

## Что изменилось

До — записи как отдельные объекты, после — компоненты с объединёнными свидетельствами. Числа получены фактическими запусками `XDG_CACHE_HOME=/tmp/xdg pixi run workflow` до и после исправления на стандартном конфиге, с теми же промежуточными Evidence. ## Голосование за вид

Слабые совпадения больше не голосуют: во всех категориях `kind.vote_identity: [strong]`. По сравнению с прежним правилом для тех же поставок переходы значений по записям:

| Категория | Переход | Число |
|---|---|---:|
| Общепит | «да» → «нет данных» | 1 |
| Алкоголь | переходов нет | 0 |
| Табак | переходов нет | 0 |

В общепите основания вида изменились у 11 объектов; у алкоголя и табака правило уже было `[strong]`. Регрессия общепита проверяет все изменившиеся основания и переход, а также неизменность остальных полей относительно эталона.
