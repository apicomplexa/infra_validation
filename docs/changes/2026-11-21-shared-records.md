# Общие записи источников и диагностика объектов — 21 ноября 2026

Сильные актуальные засчитываемые совпадения с одной карточкой Foursquare или Overture объединяют компоненты в пределах поставки. Для общепита также используется пара «номер лицензии — адрес заведения из реестра»: один номер может относиться к разным адресам или заведениям. Исключённые из подсчёта записи Overture, слабые и устаревшие находки не связывают объекты. Прежние связи relink и `egais_entity` сохранены: последняя описывает точку сопоставления v4, в том числе для табака, а не голос ЕГАИС за существование.

Диагностические строки рассчитывают флаги засчитанных источников и подтверждение по объединённому объекту; рядом сохраняются числа отдельных записей. Зависимость от Яндекса означает, что ни у одной записи компонента нет ответа, источник ещё не засчитан и его добавление меняет вердикт. Существующие построчные решения не изменены. Непустая проверка без настроенной колонки связи вызывает ошибку; отсутствующая проверка допустима.

Строка «добавлено Яндексом» проверяет все остальные независимые источники: ранее она учитывала только OSM, 2GIS и администрацию, поэтому могла приписать Яндексу подтверждение, достаточное и без него. Число записей в этой строке тоже пересчитано по исправленному условию.
