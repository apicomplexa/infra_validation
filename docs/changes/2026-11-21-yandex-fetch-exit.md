# Код завершения загрузки Яндекса

При ошибке отдельного запроса загрузка продолжалась, но команда возвращала
успешный код завершения. Из-за этого ночной конвейер мог продолжиться с
неполным кэшем.

## Что изменилось

| Сценарий | До | После |
|---|---:|---:|
| Код завершения при одной или более ошибках запросов | 0 | 1 |
| Код завершения без ошибок запросов | 0 | 0 |
| Запросов, обработанных после ошибки | вся оставшаяся очередь | вся оставшаяся очередь |

Успешные ответы по-прежнему сохраняются, неудачные повторяются при следующем запуске.
Проверка использует имитацию запросов и временный кэш; сеть не вызывается.
